# SOC Atlas — учебный сайт для Junior SOC Analyst

## Самый простой запуск
1. Скачай `SOC_Atlas_Full_Site.zip` и распакуй его.
2. Для быстрого запуска открой `SOC_Atlas_Standalone.html` в современном браузере. Это автономный файл: все страницы, стили и скрипты встроены, переходы между разделами работают внутри него.
3. Для многстраничной версии открой `SOC_Atlas/index.html`, не перемещая отдельно папки `css` и `js`. Если браузер ограничивает некоторые локальные функции, из корня проекта можно запустить `python -m http.server 8000` и открыть `http://localhost:8000/SOC_Atlas/`.

## Разделы сайта
- `index.html` — обзор и навигация.
- `roadmap.html` — учебный маршрут из девяти этапов, практика и критерии готовности.
- `academy.html` — теория для новичка: сети, IP и порты, TCP/UDP, DNS, TLS/HTTPS, события и алерты, расследование, словарь терминов и мини-разборы.
- `tools.html` — каталог учебных инструментов.
- `lab-wireshark.html` — Packet Lab: таблица синтетических пакетов, фильтры, уровни протокола, карта связей и консоль команд.
- `siem.html` — поиск по учебным журналам.
- `endpoint.html` — таймлайн endpoint-событий.
- `phishing.html` — интерактивный разбор подозрительных писем.
- `cases.html` — учебные кейсы, доказательства и передача смене.
- `detection.html` — основы проектирования правил обнаружения.
- `interview.html` — тест и подготовка к собеседованию.

## Packet Lab: команды консоли
Команда `help` показывает перечень поддерживаемых команд. Среди них: `capture start`, `capture stop`, `capture list`, `filter dns`, `connections`, `ip 10.10.5.24`, `whois 198.51.100.77`, `trace 198.51.100.77`, `block 198.51.100.77`, `stats`, `dos demo`, `ddos demo` и `clear`.

Важные ограничения: команды работают только с синтетическими данными внутри страницы; `whois` не выполняет внешний запрос и не устанавливает владельца случайного IP; `block` меняет отметку только в текущей симуляции; DoS/DDoS — анимированная концептуальная модель, которая не отправляет сетевой трафик. Packet Lab не является полной копией Wireshark, не захватывает live-трафик и не открывает PCAP-файлы.

## Сохранение данных и приватность
Это frontend-проект без backend, реальной авторизации и серверной базы данных. Некоторые отметки прогресса сохраняются в `localStorage`. Пакеты, письма, логи и кейсы синтетические. Не подключено к чужим системам и не предназначено для анализа трафика без разрешения.

## Техническая проверка
Сайт собирается скриптом `/mnt/data/build_standalone.py`; проверка структуры, внутренних ссылок, путей к ресурсам, JavaScript и целостности ZIP выполняется `/mnt/data/validate_soc.py`.


## ВАЖНО: как открыть сайт

- **Обычный локальный запуск:** скачай `SOC_Atlas_Full_Site.zip`, распакуй весь архив и открой `SOC_Atlas/index.html`. Не перемещай `index.html` отдельно от папок `css` и `js`.
- Если открываешь HTML-файл прямо в предпросмотре сайта/мессенджера, соседние файлы стилей могут быть недоступны, из-за чего будет виден только неоформленный HTML. Для такого случая используй единый файл `SOC_Atlas_Standalone.html`: в нём страницы, CSS и JavaScript встроены, навигация работает внутри файла.
- Интернет не требуется для основных функций. Все пакеты и события — учебные синтетические данные.
